Owner Admin Panel

A minimal command console for owner-only platform actions.

Security lock: This page is a frontend preview only. The live owner identity, server-side command authorization, confirmations and audit logging are not connected. No command below can change a real account or badge. Do not treat this page as an active admin login.

Owner command reference

verify-username

Grant paid green verification after payment and eligibility review.

verifyVIP-username

Grant a free gold VIP badge manually as owner.

removeV-username

Revoke a badge after confirmation; record the reason in the audit log.

1weekban-username

Apply a seven-day suspension only after a documented moderation review.

Owner security

Before any live command is enabled, the system must verify the signed-in owner server-side, validate the target account, require confirmation for sensitive actions, apply rate limits and write an immutable audit record.
